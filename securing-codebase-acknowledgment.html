Key Principles Understood

GHE as the exclusive home for internal code

All internal SentinelOne source code must remain exclusively within GitHub Enterprise (GHE). No internal code is copied, mirrored, or pushed to external or unsanctioned repositories, tools, or personal accounts.

Strict partitioning of SCM environments

Source code management environments are strictly partitioned by design. Access, sharing, and tooling integrations respect these boundaries rather than bridging code across them.

Operating confidently within the boundaries

Day-to-day work — cloning, branching, reviewing, and integrating with internal tools — is performed only within the approved, partitioned SCM environment, without introducing shortcuts that cross architectural boundaries.
